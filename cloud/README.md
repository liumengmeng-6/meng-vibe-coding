## ⚠️ 这个页面长成业务页的样子，但数据全是假的

`mock/index.html` 上展示的**行程、花费、清单**（①②③④ 四块）**全是写死的假数据**（页面顶部有醒目标注）。

只有**最底下那块「⑤ 后端连通性」是真的** —— 它真的去请求云函数。

**为什么做成这样**：这个页面的作用是**验证部署链路**（前端能不能上公网、别人能不能打开），
所以把它做成"业务页的样子"，演示的时候能一眼看出"上线之后大概长什么样"；
但它**不做真实计算** —— 真算的那套逻辑在主产品里，搬过来就等于把主产品复制一份，没必要。

- 想用真产品 → 打开仓库根目录的 `index.html`（**双击就行，不用联网**）
- 想看部署效果 / 测后端 → 用这个演示页

## 怎么用

### 打开演示页

**线上地址**（需联网）：

```
https://travel-planner-d4g8o6mee9d231c64-1499365786.tcloudbaseapp.com/backend-test/
```

**本地打开**：双击 `cloud/mock/index.html`
（页面上的假数据能看，但底部测后端那块要联网才有效）。

### 测后端连通性

拉到页面最下面「⑤ 后端连通性」区块：

1. 在输入框填云函数地址：
```
https://travel-planner-d4g8o6mee9d231c64.service.tcloudbase.com/api/health
```
2. 点「测试连通性」
3. 🟢 **绿色 + JSON** → 通了

> **地址会被记住**（存在浏览器本地），下次打开自动带出来，不用重填。

### 更直接的测法（不依赖浏览器跨域）

在浏览器地址栏**直接粘贴云函数地址**回车，或在命令行跑：

```bash
curl https://travel-planner-d4g8o6mee9d231c64.service.tcloudbase.com/api/health
```

**能看到 JSON 就说明后端通了。** 这两种方式不受跨域限制，是排查问题的第一选择。

## 常见担心：开始学后端以后，改前端会不会变麻烦？

> **不会。** 这条分隔**恰好就是为了保护这件事**才做的。
> 下面把"为什么不麻烦"讲清楚，以后心里有底。

### 为什么改前端不会牵连后端

后端代码**跑在腾讯云上**，前端代码**在你电脑上**。你在 `app.js` 里改多少行，
云上那个函数**一个字节都不会变**。

| 你想改的东西 | 会不会牵连后端 |
|---|---|
| 页面好不好看、字体、配色、动效 | ❌ 完全不牵连 |
| 加个视图、改表格排版 | ❌ 完全不牵连 |
| **改算钱的规则、改行程分配逻辑** | ❌ 完全不牵连（算钱永远在浏览器本地） |
| 加一个**纯前端**功能 | ❌ 完全不牵连 |

### 唯一会变麻烦的情况

**如果你改前端时，"顺手"让它去调后端接口** —— 比如看着 `GET /api/places` 好用，
就想让主产品的美食清单从云上拉。

那一瞬间，麻烦**不是来自后端，是来自丢掉了 `AC14`（断网可用）**：

```
现在（安全）：  改前端 ←→ 后端    两块地中间有墙，互相改不动对方
踩线之后（麻烦）：改前端 → 必须考虑"后端挂了怎么办""没网怎么办""数据格式对不上怎么办"
```

### 三种改法，对照着看

| 你想做的改动 | 麻不麻烦 | 要做什么 |
|---|---|---|
| **纯外观 / 纯交互** | 🟢 不麻烦 | 只改 `app.js` / `style.css`，跟平时一样 |
| **改算钱、改行程逻辑** | 🟢 不麻烦 | 同上（这也是为什么第 3 周**不做** `POST /api/plan` —— 就是为了保住这份自由） |
| **让主产品用云上数据** | 🟡 要先想清楚 | **必须先改 `PRD.md`**（正式改 `AC14` 口径、说明为什么放弃离线），**不能悄悄加一行 `fetch`** |

> **换句话说**：只有你**主动选择**"我要让主产品联网"时才要走流程。
> 其他时候，**后端的进度完全不会拖住你**。

### 一件要记得同步的小事

如果你改了主产品里**「城市清单」或「美食美景清单」的数据**，
云上那份数据**不会自动跟着变**（现在有两份：一份内置在 `app.js` 里，一份以后会搬到云上）。

这不是"麻烦"，是"**要记得同步一下**"。Day 16–20 真做接口时会定一个"**谁是权威**"的规矩来解决它 ——
这也是为什么现在**先写契约、不急着堆代码**。

### 一句话

> **主产品不调后端任何接口；`cloud/` 不进主产品的计算链。**
>
> 只要这条线不破，**你以后想怎么改前端都行**。
