    ④ 手动检查台任意地址

    上面三块是自动拉的。这块留着给你手动试任意地址—— 地址写错、函数没部署、跨域被拦，都能在这里试出来。

    怎么一眼认出「是跨域被拦」而不是「后端挂了」

    1. 按 F12 打开控制台，看 Console 标签：有红字 blocked by CORS policy / No 'Access-Control-Allow-Origin' header。
    2. 再看 Network 标签：那条请求状态是 (failed) 或标红， 拿不到响应体。
    3. 关键判据：把同一个地址直接粘到浏览器地址栏却能正常出 JSON （地址栏不是跨域请求，不受 CORS 管）。

    两条同时出现 = 跨域问题（接口本身是好的，是浏览器不让这个页面读它）。 只有第 3 条也失败，才是后端真的有问题。
