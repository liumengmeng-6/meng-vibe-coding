# 出行规划小助手

给预算紧张的学生党用的行程规划工具：**输入出发城市、几个想去的城市、总天数、预算**，
它给你排出「预算内最合适」的行程，并算清吃住行玩总共要花多少钱。

---

## 怎么打开（两种方式，任选）

### 方式一：双击打开（最简单，不用装任何东西）

直接双击项目文件夹里的 **`index.html`**，浏览器就会打开。

> 这个项目是**纯静态网页**，不联网、不装东西、不上传任何数据。

### 方式二：起一个本地服务（推荐，地址栏是 `localhost`）

如果双击打开有问题，或者你想用 `http://localhost:8000` 这种地址访问，就在项目目录下执行：

```bash
python -m http.server 8000
```

然后浏览器打开：**<http://localhost:8000>**

> **`python -m http.server 8000` 是什么意思？**
> 就是"用 Python 自带的简易网页服务器，在本机 8000 端口把当前文件夹当成网站提供出来"。
> `python` = 调用 Python；`-m http.server` = 运行它自带的 http 服务模块；`8000` = 端口号。
> 关掉命令行窗口（或按 `Ctrl + C`）服务就停了。
>
> 本机已装 Python 3.14.2，所以这条命令**开箱即用、不用额外安装**。

## 怎么用

1. 在「出发城市」填你的出发地，比如 `武汉`
2. 在「想去的城市」逐个填、点「添加」（最多 4 个），比如 `成都`、`重庆`、`西安`
3. 填「总天数」（含在路上的天数，2–20 天）和「预算」（可以留空，留空就只算花费不比较）
4. 点 **「生成方案」**

> **只支持国内城市。** 填了国外城市（如「东京」）**点「添加」的那一刻就会告诉你**，
> 并且**不会加进城市列表**（输入框里的字会留着，方便你改）。「出发城市」同理，**输完点到别处就会提示**。
> 国内城市即使没有精确坐标（如乌鲁木齐、三亚）也照常出方案，只是票价会标「估算值，仅供参考」。

页面会依次给出：

| 区块 | 内容 |
|---|---|
| ① 整体方案对比 | 把各种公共交通组合好的几套方案，各自总花费和在途天数，可点按钮切换 |
| ② 每日行程 | 第几天在哪个城市、当天大致安排、当天花费 |
| ③ 城际交通方案对比 | 每段路的所有可行方式（高铁 / 普速 / 长途汽车 / 拼车），标了最快和最省。**每段有「查路线」跳高德看实际距离，火车行有「去 12306 查」跳官方站核价**（见下方说明） |
| ④ 花费清单 | 城际交通、市内交通、住宿、吃、门票五项 + 合计 |
| ⑤ 预算结论 | 超了还是够用、超多少，以及省钱建议 |
| ⑥ 美食美景清单 | 可筛选（**全部 / 只吃 / 只玩**），筛完会告诉你筛出几条；内置推荐 + 你可以自己补充地点（自己加的可以删掉） |

> **自己添加的地点会记住。** 在 ⑥ 里加的地点存在你本机浏览器里，**刷新页面、关掉重开都还在**，
> 每行右端的 `×` 可以删掉它。填的城市和天数不会保留，重新打开要再填一次。

### 自己加的地点，花费怎么进总价？

**按「顶替」进，不是「相加」。** 规则很简单：

| 你在某城市填的花费 | 总价怎么变 |
|---|---|
| **没填花费**（只写了名字） | **完全不变** |
| 填了，但**没超过那几天的估算标准** | **不变**（页面上会写明"未超标准，仍按标准算"） |
| 填了，且**超过了估算标准** | **按你填的算**（总价上涨，明细里写明"按你列的花费算"） |

**为什么不是直接加上去**：总账里的「吃 80/天」「门票 60/天」本来就是按人均估的，
**里面已经包含"要吃几顿、买几张门票"**。把你填的钱再全额加上去，就是同一笔钱算两遍 ——
总价会虚高，而"够不够"正是这个工具最要紧的事，会误报"超支"。

> **所以「取较大值」的意思是**：你列的比估算高，就按你列的算（你知道得比平均值具体）；
> 你列的比估算低，就仍按估算算（一顿饭 ≠ 一整天饭钱）。
>
> ⚠️ **内置推荐清单是另一回事**：那 6 条只是"给你看看的建议"，**你并没有选中任何一条**，
> 所以它们的参考花费**完全不进总账**。

## 表里的价格不准？去官方核对（这是设计的一部分）

**表里的耗时和票价是按距离估算的，不是实时价格。** 这是有意为之，不是没做完 ——
**12306 从未开放第三方接口，携程/飞猪只给企业签约**，个人拿不到合规的票价数据。
拿不到就不假装拿得到，所以改成：**把"去哪儿核对"做成一次点击。**

| 想核什么 | 点哪里 | 跳到 |
|---|---|---|
| **火车票价 / 余票** | 火车行后面的「去 12306 查」 | **12306 官网**（铁路唯一官方售票站，最准） |
| **这段路实际多远** | 每段标题后面的「查路线」 | **高德地图**（手机上会直接唤起 App 并规划好路线） |
| **长途汽车 / 拼车路线** | 那几行后面的「看实际路线」 | **高德地图** |
| **机票** | 飞机行**没有链接** | 自己去各**航空公司官网**查（机票没有官方统一查询站） |

> **为什么飞机不给链接**：携程、去哪儿、飞猪都是**商业代销平台**，不是官方，价格随时变。
> 给它们链接等于替商业平台导流，不如直接告诉你"去航司官网"。

> **断网时这些链接打不开，但页面主体照常能用** —— 填表、生成、看行程、看花费
> 全都在你本机完成，**一个数字都不来自网络**。

## 想改点东西？

**改价格**：打开 `app.js`，最上面有个 `PRICES` 就是价目表（住宿、吃饭、门票等单价都在那）。

**改交通方式的估算参数**：`app.js` 里的 `TRANSPORT_MODES`，每种方式的时速和票价系数都在那。

**改城市数据**：`app.js` 里的 `CITY_COORDS`（24 个主要城市的坐标，用于算距离）和 `CITY_HIGHLIGHTS`（美食美景清单）。

**改支持的城市范围**：`app.js` 里的 `CN_CITIES`（国内城市白名单，370 条，用来判断"用户填的是不是国内城市"）和 `CN_CITY_ALIAS`（俗称表，如"魔都"→上海）。

> **两套城市名单，作用不一样，别改错**：
> - `CN_CITIES`（370 条）——「这个城市**认不认识**」。不认识就拦住（表单报错），不生成方案。
> - `CITY_COORDS`（24 条）——「这个城市**有没有精确坐标**」。有坐标才能算准距离和票价；没坐标的国内城市照常出方案，但票价标"估算值"。
>
> 所以填「乌鲁木齐」能出方案（在 370 条里），但票价是估算的（不在 24 条里）；填「东京」直接拦住（不在 370 条里）。

**改"不是国内城市"的提示语**：`app.js` 里的 `unsupportedCityMessage` 函数。全站只有这一处定义，
点「添加」、离开「出发城市」输入框、点「生成方案」三个时机都用它，改一次三处都变。

> 拦住国外城市这件事**发生在三个时机**（不是只在点生成时）：
> ① 点「添加」→ 不加入列表、当场出红字；② 离开「出发城市」输入框 → 当场出红字，改对了自动消失；③ 点「生成方案」→ 兜底再查一遍。
> 判断"是不是国内城市"的函数是 `isKnownChineseCity`，三处共用。

**改每日行程的建议**：`app.js` 里的 `CITY_PLAN_HINT`，一个城市一组，按第几天取。

**改「自填地点的花费怎么进总价」**：`app.js` 里的 `selfAddedSumByCity`（把某城自填的按类别汇总）、
`pickAmountsByCity`（逐城取较大值）、`perDayDetail`（账本里那两行的明细文案）。

> ⚠️ **改之前先看两处说明**：口径规则在 `PRD.md` 的 **F8**（和 **AC23**），
> 技术理由在 `TECH_DESIGN.md` 的 **约束 11**。
> **核心一条：必须是「顶替」不是「相加」** —— 直接相加会和人均标准重复计算，
> 总价虚高、误报"超支"。而且**改了"取较大值"就一定要同步改明细文案**，
> 否则会出现"用户加了地点、总价没动、页面也不解释"的静默失败。
> 自测脚本：`.git/_test-day17/selfadded-cost.js`。

> 数据都**集中放在 `app.js` 开头**那几块里，改一次只改一个地方，不会散落各处。

## 重要声明

**页面里所有价格均为学生档参考价（估算值），不是实时票价 / 房价。**

- 数据来源为经验整理 + 人工核对，**天生带误差**；
- 旺季（如国庆、春节）住宿会明显上浮，实际花费可能高出不少；
- 城际交通的耗时和票价按距离推算，不同车次差异较大，出行前请以 12306 等官方渠道为准。

**本项目不联网、不上传任何数据**，所有计算都在你的浏览器里完成。
你自己添加的地点会存在本机浏览器里（刷新还在），填的城市和天数不会保留。

> **Day 15 起的小变化**：项目里多了一块独立的 `cloud/` 目录（后端探路区），
> **它要联网** —— 但**跟主产品完全分开**，主产品**一行都没动**。
> 上面这句话说的"不联网"，指的始终是**主产品**。
