# 出行规划小助手

给预算紧张的学生党用的行程规划工具：**输入出发城市、几个想去的城市、总天数、预算**，
它给你排出「预算内最合适」的行程，并算清吃住行玩总共要花多少钱。

---

## 怎么打开（两种方式，任选）

### 方式一：双击打开（最简单，不用装任何东西）

直接双击项目文件夹里的 **`index.html`**，浏览器就会打开。

> 这个项目是**纯静态网页**，不联网、不装东西、不上传任何数据。

### 方式二：起一个本地服务（推荐，地址栏是 `localhost`）

如果双击打开有问题，或者你想用 `http://localhost:8000` 这种地址访问，就在项目目录下执行：

```bash
python -m http.server 8000
```

然后浏览器打开：**<http://localhost:8000>**

> **`python -m http.server 8000` 是什么意思？**
> 就是"用 Python 自带的简易网页服务器，在本机 8000 端口把当前文件夹当成网站提供出来"。
> `python` = 调用 Python；`-m http.server` = 运行它自带的 http 服务模块；`8000` = 端口号。
> 关掉命令行窗口（或按 `Ctrl + C`）服务就停了。
>
> 本机已装 Python 3.14.2，所以这条命令**开箱即用、不用额外安装**。

## 怎么用

1. 在「出发城市」填你的出发地，比如 `武汉`
2. 在「想去的城市」逐个填、点「添加」（最多 4 个），比如 `成都`、`重庆`、`西安`
3. 填「总天数」（含在路上的天数，2–20 天）和「预算」（可以留空，留空就只算花费不比较）
4. 点 **「生成方案」**

页面会依次给出：

| 区块 | 内容 |
|---|---|
| ① 整体方案对比 | 把各种公共交通组合好的几套方案，各自总花费和在途天数，可点按钮切换 |
| ② 每日行程 | 第几天在哪个城市、当天大致安排、当天花费 |
| ③ 城际交通方案对比 | 每段路的所有可行方式（高铁 / 普速 / 长途汽车 / 拼车），标了最快和最省 |
| ④ 花费清单 | 城际交通、市内交通、住宿、吃、门票五项 + 合计 |
| ⑤ 预算结论 | 超了还是够用、超多少，以及省钱建议 |
| ⑥ 美食美景清单 | 可筛选（**全部 / 只吃 / 只玩**），筛完会告诉你筛出几条；内置推荐 + 你可以自己补充地点（自己加的可以删掉） |

> **自己添加的地点会记住。** 在 ⑥ 里加的地点存在你本机浏览器里，**刷新页面、关掉重开都还在**，
> 每行右端的 `×` 可以删掉它。填的城市和天数不会保留，重新打开要再填一次。

## 想改点东西？

**改价格**：打开 `app.js`，最上面有个 `PRICES` 就是价目表（住宿、吃饭、门票等单价都在那）。

**改交通方式的估算参数**：`app.js` 里的 `TRANSPORT_MODES`，每种方式的时速和票价系数都在那。

**改城市数据**：`app.js` 里的 `CITY_COORDS`（城市坐标，用于算距离）和 `CITY_HIGHLIGHTS`（美食美景清单）。

**改每日行程的建议**：`app.js` 里的 `CITY_PLAN_HINT`，一个城市一组，按第几天取。

> 数据都**集中放在 `app.js` 开头**那几块里，改一次只改一个地方，不会散落各处。

## 重要声明

**页面里所有价格均为学生档参考价（估算值），不是实时票价 / 房价。**

- 数据来源为经验整理 + 人工核对，**天生带误差**；
- 旺季（如国庆、春节）住宿会明显上浮，实际花费可能高出不少；
- 城际交通的耗时和票价按距离推算，不同车次差异较大，出行前请以 12306 等官方渠道为准。

**本项目不联网、不上传任何数据**，所有计算都在你的浏览器里完成。
你自己添加的地点会存在本机浏览器里（刷新还在），填的城市和天数不会保留。
